# P1 第一批：风险事件、持续提醒与证据

用户已确认：未配置现场规则时保留待核验观察；配置区域/类别后才判风险；短暂丢失默认 3 秒，持续提醒默认 60 秒，均可配置、需现场校准。本轮不宣称完成全部 P1、现场精度或任意遮挡身份保持。

## 行为契约

1. 检测协议 v4 增加 MISSING、observedThrough。跟踪存活按有效观测时间计算，默认 3 秒；没有图像/处理失败不代表风险解除。v3 历史补传保持兼容，并标识旧协议状态。
2. 风险事件独立保存 PRESENT/MISSING/CLEARED/INTERRUPTED，人工处置与已读分开。无规则为 OBSERVATION；有规则按归一化图像矩形区域、类别、当前分数与停留时间判断。默认规则停留 2 秒、分数 0.5，管理员可调整。
3. 只在同摄像头/会话、短时间、相同自动类别、位置相容且候选唯一时续接断轨。多个候选或证据不足新建并标注不确定。跨会话不自动合并。离开后再次进入形成新事件，保留轨迹关联历史。
4. 首次、持续、风险升高分别写入持久提醒记录，唯一键保证重投不重复。默认每 60 秒持续提醒，仅由新的、时间新鲜的有效观测触发；已读不等于解除，人工已处理仍可收到持续风险复核提醒，不覆盖原人工结果。断流期间不凭计时器虚构风险进展。
5. 页面同时展示规则依据、自动与人工类别、检测与风险状态、首末时间、处置与提醒历史、轨迹关联。截图经独立持久队列上传，服务身份与用户读取授权隔离，限大小/配额；失败不阻断关键事件。完整长录像/对象存储归档不在本批截图交付范围内。
